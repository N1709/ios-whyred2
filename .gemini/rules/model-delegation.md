# Model Delegation Rules

When delegating tasks via OpenCode CLI:
- Use **MiniMax M3.1 Flash** (`opencode run -m opencode/minimax-m3.1-flash-free --auto "<prompt>"`) for reasoning tasks, theory debates, hardware register deductions, and hypothesis analysis.
- Use **DeepSeek v4.1 Flash** (`opencode run -m opencode/deepseek-v4.1-flash-free --auto "<prompt>"`) for debugging, investigating code faults, and authoring code modifications.
